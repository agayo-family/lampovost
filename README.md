# Ламповость — сайт-фотоальбом (v3)

Главные фото и музыка **не зависят от Яндекс Диска**: они хранятся прямо внутри проекта и после публикации отдаются с того же домена, что и сайт. Яндекс Диск используется только как дополнительная кнопка «все фотографии» в начале и конце страницы.

## Что изменено в v3

- больше фраз на самих полароидах и поверх отдельных фотографий;
- добавлены фразы про молодость;
- вся лексика сайта приведена к формату «вечер», «момент», «молодость»;
- фотографии теперь собираются в группы по 1–3 кадра, будто их бросили на стол;
- сайт стал заметно короче;
- 6 разных схем расположения фотографий;
- разные способы «крепления»: обычный скотч, два кусочка скотча, скотч по углам, боковой скотч, кнопка, скрепка, без крепления;
- заголовки сделаны грубым рисованным шрифтом в духе референса;
- кнопки скачивания и основные действия получили рукописный шрифт;
- добавлены разные появления: снизу, слева, справа, поворот, лёгкое размытие;
- добавлена анимация печатающегося текста;
- кнопка перехода на Яндекс Диск есть в начале и в конце;
- полноэкранный просмотр и скачивание оригинала сохранены;
- `photos.zip` по-прежнему создаётся автоматически при сборке.

## Куда класть фотографии

Положи оригинальные файлы в:

`public/photos/`

Поддерживаются `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Порядок определяется именем файла. Если нужен конкретный порядок, используй:

`001.jpg`, `002.jpg`, `003.jpg` ...

Не пережимай изображения вручную — посетитель скачивает тот оригинал, который лежит в этой папке.

## Куда класть музыку

Положи аудиофайл в:

`public/music/`

Поддерживаются `.mp3`, `.m4a`, `.wav`, `.ogg`, `.aac`.

Если файлов несколько, сайт сначала ищет имя с `лагер`, `SALUKI` или `Friendly`, иначе использует первый файл по алфавиту.

Пример:

`SALUKI - лагерная (Instrumental).mp3`

Используй файл, на публикацию которого у тебя есть необходимые права.

## Как проверить на компьютере

Нужны Node.js 20+ и Python 3.

В папке проекта:

```bash
npm run dev
```

После этого открой:

`http://localhost:4173`

## Как опубликовать на Vercel

1. Создай новый репозиторий GitHub.
2. Загрузи содержимое этой папки в корень репозитория.
3. В Vercel нажми `Add New → Project`.
4. Выбери репозиторий.
5. Framework Preset: `Other`.
6. Build Command: `npm run build`.
7. Output Directory: `dist`.
8. Environment Variables не нужны.
9. Нажми Deploy.

После изменения фотографий или музыки сделай новый deploy.

## Что делает сборка

`scripts/build.mjs` автоматически:

- находит все фотографии в `public/photos`;
- создаёт `content.json`;
- копирует оригиналы в готовый сайт;
- создаёт `photos.zip` со всеми фотографиями;
- находит музыку в `public/music`;
- собирает готовую папку `dist`.

Список фотографий в коде вручную менять не нужно.
