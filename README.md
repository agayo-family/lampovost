# Ламповость + вайб

Одностраничный фотоальбом, который автоматически подтягивает фотографии из публичной папки Яндекс Диска:
https://disk.yandex.ru/d/H10Ne-YjYh7yzQ

## Что уже работает

- Очень длинная вертикальная лента с полароидными кадрами.
- Чередование фотографий слева/справа/по центру.
- Тёплая фактура дерева/бумаги и декоративные «выжженные» надписи.
- Полноэкранный просмотр кадра.
- Кнопка скачивания оригинала у каждой фотографии.
- Кнопка «скачать все фотографии» — Яндекс Диск формирует архив папки.
- Ленивая загрузка изображений для мобильных устройств.
- Музыкальный плеер после первого пользовательского нажатия.

## Музыка

Чтобы музыка заработала, положите аудиофайл, который у вас есть право использовать, в ту же публичную папку Яндекс Диска. Поддерживаются mp3/m4a/aac/wav/ogg. Сайт автоматически найдёт аудиофайл и включит его после нажатия «открыть воспоминание».

## Деплой на Vercel

1. Загрузить папку проекта в GitHub.
2. Import Project в Vercel.
3. Framework Preset: Other.
4. Build Command и Output Directory оставить пустыми.
5. Deploy.

API-функции `/api/photos`, `/api/download`, `/api/download-all`, `/api/audio` работают как Vercel Functions и обращаются к публичному API Яндекс Диска.
