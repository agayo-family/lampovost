# Ламповость — сайт-фотоальбом (v8)

Главные фотографии и музыка хранятся внутри самого проекта. Яндекс Диск используется только как дополнительная кнопка «все фотографии» в начале и конце страницы.

## Что исправлено в v8

- убраны искусственные прямоугольные «блоки» вокруг групп фотографий;
- фотографии больше не режутся под фиксированное соотношение сторон: показывается весь исходный кадр;
- композиция снова ощущается как физический фотоальбом/стол с полароидами, а не как карточный интерфейс;
- все декоративные надписи и царапины являются частью страницы и прокручиваются естественно вместе с ней — ничего не «приклеено» к экрану;
- добавлена более заметная фактура тёмной поверхности, пыль, мелкие царапины и потёртости;
- `ВЫ + AGAYO = ♡` выполнено как процарапанная надпись, а не обычный текст;
- добавлены редкие фоновые граффити и маленькие детали, которые находятся за фотографиями и не перекрывают подписи;
- все фотографии обязательно чем-то «закреплены»: скотчем, двойным скотчем, по углам или кнопкой;
- сохранены фразы про молодость, ламповость и вечер; слово «ночь» не используется;
- сохранены анимации появления и печатающегося текста, но фоновые надписи больше не двигаются отдельно от страницы;
- сохранены скачивание каждого оригинала, общий `photos.zip`, музыка и кнопки Яндекс Диска.

## Куда класть фотографии

Положи оригинальные файлы в:

`public/photos/`

Поддерживаются `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Чтобы управлять порядком, называй файлы:

`001.jpg`, `002.jpg`, `003.jpg` ...

Фотографии не сжимаются сборщиком. На сайте показывается весь кадр, а скачивается исходный оригинал.

## Куда класть музыку

Положи аудиофайл в:

`public/music/`

Поддерживаются `.mp3`, `.m4a`, `.wav`, `.ogg`, `.aac`.

Если файлов несколько, сайт сначала ищет имя с `лагер`, `SALUKI` или `Friendly`, иначе использует первый файл по алфавиту.

## Как проверить локально

В папке проекта:

```bash
npm run dev
```

Затем открой:

`http://localhost:4173`

## Публикация на Vercel

1. Загрузи содержимое этой папки в корень GitHub-репозитория.
2. В Vercel выбери `Add New → Project`.
3. Framework Preset: `Other`.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Environment Variables не нужны.
7. Нажми Deploy.

После изменения фотографий или музыки нужен новый deploy.
