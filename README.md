# Ламповость — сайт-фотоальбом (v2)

Эта версия **не использует Яндекс Диск вообще**. Фотографии и музыка хранятся прямо внутри проекта и после публикации раздаются с того же домена, что и сайт.

## Что уже сделано

- длинная вертикальная история;
- стилистика по референсу: чёрная потёртая поверхность, рваный картон, красная краска, рукописные каракули, скотч, полароиды;
- чередование фото слева/справа/по центру;
- полноэкранный просмотр;
- скачивание каждого оригинала;
- автоматическая сборка `photos.zip` для кнопки «скачать все фотографии»;
- музыка запускается после первого нажатия и плавно появляется;
- адаптация под телефон и компьютер;
- никаких внешних фото-хостингов и API.

## Куда класть фотографии

Положи **оригинальные** файлы в:

`public/photos/`

Поддерживаются:

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.avif`

Порядок фотографий определяется именем файла. Если нужен конкретный порядок, лучше переименовать:

`001.jpg`, `002.jpg`, `003.jpg` ...

Не пережимай изображения вручную: посетитель сможет скачать именно тот оригинал, который ты положишь в эту папку.

## Куда класть музыку

Положи аудиофайл в:

`public/music/`

Поддерживаются `.mp3`, `.m4a`, `.wav`, `.ogg`, `.aac`.

Если в папке несколько файлов, сайт сначала ищет файл, в названии которого есть `лагер`, `SALUKI` или `Friendly`, иначе берёт первый по алфавиту.

Пример имени:

`SALUKI - лагерная (Instrumental).mp3`

Используй файл, на публикацию которого у тебя есть необходимые права.

## Как проверить на компьютере

Нужен Node.js 20+ и Python 3.

В папке проекта:

```bash
npm run dev
```

Открой:

`http://localhost:4173`

## Как опубликовать на Vercel

1. Создай новый репозиторий GitHub.
2. Загрузи **содержимое этой папки** в корень репозитория.
3. В Vercel нажми `Add New → Project`.
4. Выбери репозиторий.
5. Framework Preset: `Other`.
6. Build Command: Vercel автоматически увидит `npm run build`. Если не увидел — впиши его вручную.
7. Output Directory: `dist`.
8. Environment Variables не нужны.
9. Нажми Deploy.

После каждого изменения фотографий или музыки нужен новый deploy — это плата за то, что файлы теперь полностью независимы от Яндекс Диска.

## Что делает сборка

`scripts/build.mjs` автоматически:

- находит все фото в `public/photos`;
- создаёт `content.json`;
- копирует фото в финальный сайт;
- создаёт `photos.zip` со всеми оригиналами;
- находит музыку в `public/music`;
- собирает готовую папку `dist`.

Править список фотографий в коде вручную не нужно.
